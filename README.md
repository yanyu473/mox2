# 山河问鼎 · 九州宏图

一款古风三维策略游戏，六大诸侯国争霸九州，招募士兵、发展经济、研究科技、攻城略地，问鼎天下。

## 🎮 在线游玩

**[点击开始游戏](https://yanyu473.github.io/mox2/)**

## 游戏特色

- 🌄 **480×480 三维大地图** - 山脉、平原、河流、森林完整地形
- ⚔️ **实时战斗动画** - 士兵列阵对打、弓箭齐射、兵刃碰撞
- 🏰 **六大诸侯国** - 朔云、锦川、临江、北原、苍海、雾南，各有特色
- 📜 **完整内政系统** - 建造、招募、科技、外交
- 🎵 **古风音乐音效** - 五声音阶合成背景音乐 + 十数种场景音效
- 🤖 **智能AI** - 各国自动发展、主动扩张
- 💾 **自动存档** - 本地存档，随时继续

## 操作说明

| 操作 | 说明 |
|------|------|
| WASD / 方向键 | 移动视角 |
| 鼠标左键 | 选择城邑/地块 |
| 鼠标右键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 空格 | 结束本旬 |
| ESC | 取消/关闭 |

## 胜利条件

据有承天府（帝都）、至少 4 座诸侯都城与 15 个节点，连续守住 5 旬。

## 技术栈

- Three.js 3D 渲染引擎
- Web Audio API 音乐音效合成
- 纯前端单文件，无需后端
- 支持 PC / 平板 / 手机
